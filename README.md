# 💱 Live Currency Converter

A modern and responsive live currency converter built using HTML, CSS, JavaScript, jQuery, and AJAX.  
Convert currencies in real-time with a beautiful gradient UI, dark mode, swap functionality, and recent conversion history.

---

## 🚀 Features

- 🌍 Real-time currency conversion
- 🔄 Live exchange rates API integration
- 💱 Swap currencies instantly
- 🌙 Dark / Light mode toggle
- 📋 Multiple currency dropdown selection
- ⚡ AJAX requests using jQuery
- 📱 Fully responsive design
- 📌 Recent conversion history
- 📋 Copy conversion result button
- 🌐 Online / Offline status indicator
- ⏱️ Last updated exchange rate timer
- 🎨 Modern gradient glassmorphism UI

## ⚙️ How It Works

1. Enter the amount
2. Select source currency
3. Select target currency
4. Click the Convert button
5. Get instant live conversion results

The app fetches real-time exchange rates using AJAX requests from the exchange rate API.
